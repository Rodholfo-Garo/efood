# 🛒 eFood – E-commerce com Checkout Completo

Este é um projeto pessoal de e-commerce desenvolvido com React, Redux Toolkit e TypeScript, como parte da formação "Profissão: Desenvolvedor Full Stack Python" da [EBAC](https://ebaconline.com.br).

## 🔗 Acesse o projeto online
[https://efood-bice-xi.vercel.app/](https://efood-bice-xi.vercel.app/)

---

## 🧠 Tecnologias utilizadas

- ✅ React
- ✅ Redux Toolkit
- ✅ RTK Query
- ✅ TypeScript
- ✅ Formik + Yup
- ✅ Styled Components
- ✅ Design Responsivo

---

## 📦 Funcionalidades

- Fluxo completo de checkout (carrinho → entrega → pagamento → confirmação)
- Validação de formulários com feedback visual
- Integração com API externa via RTK Query
- Componentes reutilizáveis e arquitetura modular
- Tipagem forte com TypeScript

---

## 🚀 Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/Rodholfo-Garo/efood.git

# Acesse a pasta
cd efood

# Instale as dependências
npm install

# Rode o projeto
npm start
